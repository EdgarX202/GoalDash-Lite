# Contributing to This Project

Thank you for contributing to this project.

This is a **private, proprietary project** intended for future commercial distribution. By accessing or contributing to this repository, you agree to follow the guidelines below.

## 1. Private Repository

This repository and its contents are private and confidential.

Do not share access to the repository with anyone who has not been authorised by the project owner.

Do not:

* Make the repository public.
* Create public mirrors or copies of the repository.
* Upload project code to other public repositories.
* Share source code, files, screenshots, documentation, or other proprietary materials outside the authorised team.
* Give repository credentials or access tokens to other people.

## 2. Purpose of Access

Access to this repository is provided solely for the purpose of contributing to the development, testing, maintenance, or improvement of this project.

Contributors must not use the project's code, designs, architecture, business logic, or other proprietary materials for unrelated projects or personal products without written permission from the project owner.

## 3. Do Not Copy or Reuse Project Code

Unless explicitly authorised by the project owner, contributors must not:

* Copy source code into another project.
* Reuse substantial portions of the code in personal or commercial projects.
* Create a competing product using the project's proprietary implementation.
* Reproduce the project's architecture or proprietary functionality elsewhere.
* Distribute or sell any portion of the project.
* Publish project code or proprietary materials online.

Small pieces of code that are independently developed and not proprietary to this project may be used elsewhere where appropriate. When in doubt, ask the project owner before reusing anything.

## 4. Contributions

Only submit work that you have the right to contribute.

Do not submit:

* Code copied from proprietary projects without permission.
* Code containing confidential information belonging to another organisation.
* Third-party software without checking its licensing requirements.
* Credentials, API keys, passwords, private keys, or other secrets.
* Personal or sensitive information that is not required by the project.

Before submitting a contribution, review the changes to ensure that no confidential information or secrets have been included.

## 5. Ownership of Contributions

Contributing to this project does not automatically grant you ownership of the project as a whole.

All contributors retain any rights they may have in original work they independently create, unless a separate written agreement states otherwise. The project owner may require contributors to enter into a separate **Contributor Agreement or Intellectual Property Assignment Agreement** before accepting contributions.

Such an agreement may establish the project's rights to use, modify, distribute, license, sell, and commercially exploit contributed work.

## 6. Commercialisation

The project may be commercially released, licensed, sold, or distributed through a marketplace or other commercial channel in the future.

Contributors must not independently:

* Sell the project.
* License the project.
* Publish the project.
* Distribute copies of the project.
* Offer the project as a competing product or service.
* Represent themselves as the owner of the project.

Commercial decisions regarding the project are reserved for the project owner unless otherwise agreed in writing.

## 7. Development Guidelines

Contributors should:

* Keep changes focused and relevant to the task.
* Follow the existing project structure and coding conventions.
* Write clear, maintainable code.
* Add or update documentation when appropriate.
* Test changes before submitting them.
* Avoid unnecessary changes to unrelated parts of the project.
* Clearly describe what was changed and why in pull requests.

## 8. Pull Requests

Before opening a pull request:

1. Make sure the code works as intended.
2. Test relevant functionality.
3. Check that no secrets or sensitive information have been committed.
4. Review your own changes.
5. Provide a clear description of the changes.
6. Explain any known limitations or issues.

Pull requests may be reviewed, modified, rejected, or merged at the discretion of the project owner.

## 9. Dependencies and Third-Party Code

Before adding a new dependency, check its licence and confirm that it is compatible with the project's intended commercial use.

Do not introduce third-party code that imposes licensing requirements that could conflict with the project's commercial distribution without prior approval.

When required, include appropriate attribution and licence information for third-party software.

## 10. Security

Never commit:

* Passwords
* API keys
* Authentication tokens
* Private keys
* Database credentials
* Environment secrets
* Production credentials

Use environment variables or an appropriate secrets-management system instead.

If you discover a security vulnerability, **do not create a public issue**. Contact the project owner privately.

## 11. Confidentiality

Information obtained through participation in this project should be treated as confidential unless it has been explicitly made public by the project owner.

This includes, but is not limited to:

* Source code
* Architecture
* Algorithms
* Product plans
* Business logic
* Internal documentation
* Unreleased features
* Customer or business information
* Development processes
* Marketplace plans
* Credentials and technical infrastructure

Do not disclose confidential information to people outside the authorised team.

## 12. Questions and Approval

If you are unsure whether something can be copied, reused, disclosed, published, or added to the project, **ask the project owner before doing so**.

When in doubt, assume that non-public project materials are confidential and proprietary.

## 13. Agreement

By contributing to this repository, you acknowledge that:

* This is a private and proprietary project.
* Repository access is provided for authorised project work only.
* You will not copy, distribute, publish, or commercially exploit the project without permission.
* You will protect confidential project information.
* You will follow the project's contribution and security guidelines.
* Additional written agreements may apply to contributions and intellectual property.
