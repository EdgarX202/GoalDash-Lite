# Financial Assistant 
Prototype level web app.<br>
<br>
<strong>Mission statement</strong>: To reward users for their accomplishments and motivate them throughout the financial journey. <br>
<br>
GoalDash Lite app allows users to create various financial goals (savings, debt, purchases etc.) and track the progress of it.<br>
Users can either manually add money to their goals, or use automatic consistent contributions.<br>
<br>
GoalDash Lite rewards users for completing goals with in-app currency, achievements, milestones, and XP points.<br>


## Phase One
Core Goals System 
- User Account Management
- Goal Creation and Management
- Goals Dashboard

## Phase Two
Progression System
- XP System
- XP Levels
- Achievements
- Milestones
- Rewards
